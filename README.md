# RoguelikeTD

A roguelike tower-defense game built with Unity (Tuanjie Engine 2022.3.61t15).

## Requirements

- Tuanjie Engine / Unity 2022.3.61t15
- .NET / Visual Studio 2022 (optional, for IDE support)

## Getting started

1. Open the project folder in Tuanjie Hub / Unity Hub.
2. Open `Assets/Scenes/SampleScene.scene`.
3. Press Play.

## Layout

- `Assets/Scripts` — gameplay code (managers, entities, commands)
- `Assets/Scenes` — scenes
- `Assets/Sprites`, `Assets/Animations` — art
- `ProjectSettings`, `Packages` — project configuration

Unity-generated folders (`Library/`, `Temp/`, `Logs/`, `obj/`) are not tracked.
